## 一、为什么需要成本优化与 ROI 分析

多数团队在 VPS 上的支出里 **30%~45% 是沉默浪费**：闲置实例、过量配置、未压缩存储、跨区流量、忘记关停的测试机。成本优化的目标不是盲目省钱，而是把每元支出映射到可衡量业务价值。

ROI 视角回答三个核心问题：

1. **该不该扩容？** 新增实例的边际收益是否大于边际成本？
2. **该不该买长期套餐？** 多年付折扣是否真能覆盖灵活性损失？
3. **该不该换云？** 迁移 + 学习成本是否小于长期节省？

本手册框架：建成本模型 → 用 ROI 判断 → 用策略执行 → 用监控与 FinOps 持续治理。

## 二、成本模型：先搞清楚钱花在哪

### 2.1 定价模型分析

| 模型 | 计费粒度 | 灵活性 | 单价 | 适用场景 |
|------|----------|--------|------|----------|
| 按需 On-Demand | 按秒/小时 | 最高 | 最高 | 短期测试、突发、未知负载 |
| 预留 Reserved | 预付+时长承诺 | 低 | 低 30%~70% | 长期稳定负载（≥70% 利用率） |
| 竞价 Spot | 动态价 | 中（可回收） | 低 60%~90% | 可中断批处理、CI、渲染 |
| 流量包/带宽峰值 | 按出量 | 中 | 视地区 | 内容分发、API 网关 |

单价最低 ≠ 总成本最低：预留需"承诺利用率"撑住，竞价需"容错架构"兜底，否则节省变故障。

### 2.2 TCO 总拥有成本计算

TCO = 直接成本 + 间接成本 + 隐性成本。只看月账单会系统性低估真实支出。

```
TCO(月) = 计算实例 + 块存储 + 对象存储/备份 + 出网带宽
        + 负载均衡/公网IP + 快照/镜像 + 监控日志
        + 运维人力摊销（工时×时薪/月）
        + 故障停机机会成本（SLA 外损失）
        + 迁移/学习成本摊销
```

**示例**：月付 ¥120 的 2C4G 实例，加 80GB SSD(¥20)、200GB 出流量(¥40)、公网 IP(¥10)、每日 15 分钟运维(¥150)、年 4 小时停机损失摊月(¥80)，真实 TCO ≈ ¥420/月，是账单价的 **3.5 倍**。

### 2.3 隐藏成本识别

- **出网带宽 Egress**：入站常免费，出站按量，跨国/跨区单价极高。
- **快照蔓延**：自动快照留存 30 天，增量累积可能超实例盘。
- **闲置公网 IP / 负载均衡**：不开机也计费。
- **日志与监控存储**：高频日志 + 长保留 = 隐性大头。
- **私网跨区 / NAT 网关**：部分云对私网跨区也计费。
- **汇率与税制**：美元定价 + 增值税 + 汇率波动。

经验法则：把"账单金额 × 1.8~2.5"作为 TCO 估算下限，逐项核对再下结论。

### 2.4 按服务拆解成本

治理前先按服务/标签拆分：

```
计算 45% | 存储 18% | 带宽 20% | 网络组件 7% | 监控日志 5% | 其他 5%
```

哪一栏超 30%，哪栏就是优化第一优先级。

## 三、ROI 分析：每一分钱是否值得

### 3.1 ROI 基础公式

```
ROI(%) = (收益 - 成本) / 成本 × 100%
净节省  = |优化后月成本 - 优化前月成本|
投入    = 改造工时×时薪 + 工具/迁移费 + 风险准备金
回收期(月) = 投入 / 月节省
```

**决策阈值**：回收期 < 3 月 = 立即做；3~6 月 = 排期做；> 6 月 = 评估再做。

### 3.2 单用户成本 Cost Per User

```
单用户月成本 = 月度 TCO / 活跃用户数
单用户毛利   = 客单价 - 单用户月成本
```

单用户成本 > 客单价 40% → 架构/定价有问题；< 10% → 通常还有 Right-sizing 空间。

### 3.3 成本 vs 性能权衡

用"单位成本性能"衡量：

```
性价比指数 = 关键指标(QPS/吞吐/渲染帧) / 月 TCO
```

提升配置只带来 10% 性能却 50% 成本 → 指数下降，不值得；带来 80% 性能且 20% 成本 → 指数上升，值得。

### 3.4 长期合约折扣临界点

```
设按需月单价 P，预留折扣率 d，合约月数 M，迁移沉没 S
盈亏平衡利用率 U* = S / (P × d × M)
```

例：按需 ¥200/月，3 年付 5 折（实付 ¥100/月），迁移沉没 ¥2000：
U* = 2000 / (100×36) ≈ 0.56 → 利用率 > 56% 且能稳跑 3 年才划算；低于此，按需更优（保留灵活性）。

## 四、优化策略

### 4.1 预留实例 vs 按需实例

| 负载特征 | 推荐 | 理由 |
|----------|------|------|
| 7×24 稳定基载（>70%） | 预留/包年 | 锁折扣，回收期最短 |
| 工作日 9~18 波动 | 按需+定时开关 | 不为闲置买单 |
| 季节性峰值 | 基载预留+峰值按需 | 混合覆盖 |
| 实验/预发 | 按需+自动关停 | 灵活性优先 |

**混合策略**：60%~70% 稳定基载用预留锁定，30%~40% 用按需/竞价吸收波动。比全预留省 15%~25%，比全按需省 40%~55%。

### 4.2 竞价 Spot 实例策略

竞价可便宜 60%~90%，但会被回收。落地要点：

1. **无状态化**：任务从对象存储/队列取数，结果写回，实例随时可弃。
2. **检查点 Checkpoint**：长任务每 N 分钟存进度，回收后断点续跑。
3. **多规格回退**：备 3+ 种实例类型，一种回收自动换另一种。
4. **多可用区分散**：避免单区现货枯竭。
5. **出价上限**：设为按需价 100%~120%，防价格尖峰反噬。

适用：CI 构建、数据批处理、视频转码、模型训练、爬虫、压测。

### 4.3 存储分层

按访问频率分层，单价差可达 10 倍以上：

| 层 | 访问频率 | 相对单价 | 用途 |
|----|----------|----------|------|
| 热 SSD/高性能盘 | 实时 | 1.0× | 数据库、活跃文件 |
| 温 标准对象存储 | 天~周 | 0.3× | 备份、近期日志 |
| 冷 低频/归档 | 月~年 | 0.05×~0.1× | 合规归档、旧快照 |
| 删除/生命周期 | — | 0× | 过期日志、临时文件 |

落地：生命周期规则自动把 30 天前日志转冷、365 天前删除；快照只留 7 天日常 + 1 份月度。

### 4.4 带宽优化

出网流量常是隐性"成本黑洞"：

- **CDN 前置**：静态资源走 CDN，回源流量省 60%~80%。
- **压缩**：开 Brotli/gzip，文本类体积降 60%~70%。
- **协议优化**：HTTP/2、TLS 会话复用、连接复用。
- **就近部署**：用户集中区放同区域，减跨区/跨国流量。
- **流量包/95 计费**：大流量选 95 峰值或包月带宽，比按量更稳。

### 4.5 资源 Right-sizing

过量配置是最大浪费源：

1. **采集基线**：连续 2~4 周采集 CPU/内存/IO/网络 P95。
2. **找浪费**：CPU 均值 <20% 且峰值 <50% → 可降配；内存常驻 <40% → 可降配。
3. **阶梯验证**：先降一档跑 1 周，错误率/延迟无恶化再固化。
4. **自动复核**：监控告警 + 脚本周期复核。

典型收益：降配 1~2 档省 30%~50% 计算费，多数业务无感知。

### 4.6 自动扩缩容 Auto-scaling

用弹性换成本：

- **定时扩缩**：按业务日历（大促前 1 小时扩容）。
- **指标驱动**：CPU >65% 扩容、<25% 缩容，设最小/最大实例数兜底。
- **预测式扩缩**：基于历史规律提前扩容，避冷启动延迟。
- **缩容保护**：设冷却时间，防抖动频繁伸缩。

注意：自动扩缩必须配合健康检查与优雅下线，否则省钱却丢请求。

### 4.7 成本分配标签

无标签 = 无法归因。强制标签策略：

```
必填：owner(责任人) env(prod/staging/dev) team(团队)
      cost-center(成本中心) project(项目) optimized(是否right-sizing)
```

用标签做 Showback：各团队看自己真实 TCO；做 Chargeback：成本回流对应预算。

### 4.8 多云成本对比

勿被单云锁定。对比维度：

- **同规格单价**（2C4G / 4C8G 标准化）
- **出网流量单价**（常被忽略）
- **同区域延迟**（影响体验与留存）
- **折扣政策**（长期/新用户/续费）
- **隐性费用**（快照、IP、负载均衡、支持费）

策略：核心稳定负载放性价比最高云，弹性/测试放有竞价资源的云，避免单点也避免过度分散（分散本身增运维成本）。

## 五、FinOps 实践

FinOps = 工程 + 财务 + 业务协作文化，目标"在正确时间用正确成本交付价值"。

### 5.1 预算告警

三级告警，避免月底"账单惊吓"：

```
绿区：实际 < 预算 80%   → 正常
黄区：80%~100%         → 周报提醒负责人
红区：> 100%            → 立即告警 + 自动限流/暂停非关键实例
```

### 5.2 Showback / Chargeback

- **Showback（展示）**：按标签展示成本给各团队，不真正扣款，培养成本意识。
- **Chargeback（分摊）**：计入团队/项目预算，与绩效/资源申请挂钩。

新手从 Showback 起步，成熟后再上 Chargeback，否则易引发甩锅。

### 5.3 成本异常检测

异常类型：突增（某实例出流量单日 ×10，或被盗刷/死循环）、静默增长（快照每月 +15%，生命周期失效）、结构性偏移（prod 占比异常升，环境串用）。

检测：对每日成本做移动平均 + 3σ 阈值；或同比/环比偏离 > 30% 触发。

### 5.4 成本优化检查清单

- [ ] 导出近 3 月账单，按服务/标签拆分
- [ ] 识别 Top 3 成本项并设优化目标
- [ ] 稳定基载评估预留（回收期 < 6 月）
- [ ] 可中断负载迁竞价实例
- [ ] 存储配生命周期分层
- [ ] 静态资源接 CDN + 压缩
- [ ] 所有实例打必填成本标签
- [ ] 配预算三级告警
- [ ] 设 Right-sizing 复核周期（季度）
- [ ] 非生产环境配定时关停
- [ ] 建月度成本评审机制

## 七、实用脚本 PowerShell

### 7.1 单实例月度 TCO（含隐性成本）

```powershell
function Get-InstanceTCO {
    param(
        [double]$ComputeMonthly, [double]$BlockStorage,
        [double]$EgressGB, [double]$EgressRate,
        [double]$PublicIP, [double]$OpsMinutesDay,
        [double]$HourlyRate, [double]$DowntimeHoursYr,
        [double]$DowntimeLossPerHr
    )
    $ops = $OpsMinutesDay * 30 * ($HourlyRate / 60)
    $dt  = ($DowntimeHoursYr * $DowntimeLossPerHr) / 12
    $eg  = $EgressGB * $EgressRate
    $tco = $ComputeMonthly + $BlockStorage + $eg + $PublicIP + $ops + $dt
    [PSCustomObject]@{
        Compute=$ComputeMonthly; Storage=$BlockStorage; Egress=$eg
        PublicIP=$PublicIP; Ops=$ops; Downtime=$dt
        TCO=[math]::Round($tco,2); BillMultiple=[math]::Round($tco/$ComputeMonthly,2)
    }
}
Get-InstanceTCO -ComputeMonthly 120 -BlockStorage 20 -EgressGB 200 -EgressRate 0.2 `
                -PublicIP 10 -OpsMinutesDay 15 -HourlyRate 60 -DowntimeHoursYr 4 -DowntimeLossPerHr 240
```

### 7.2 ROI / 回收期

```powershell
function Get-OptimizationROI {
    param([double]$BeforeMonthly,[double]$AfterMonthly,[double]$Investment)
    $save = $BeforeMonthly - $AfterMonthly
    if ($save -le 0) { Write-Warning "该优化不省钱，ROI 为负"; return }
    $payback = $Investment / $save
    [PSCustomObject]@{
        MonthlySave=[math]::Round($save,2)
        AnnualSave=[math]::Round($save*12,2)
        PaybackMonths=[math]::Round($payback,1)
        Verdict=if($payback-le 3){"立即做"}elseif($payback-le 6){"排期做"}else{"评估再做"}
    }
}
Get-OptimizationROI -BeforeMonthly 420 -AfterMonthly 260 -Investment 900
```

### 7.3 预算三级告警

```powershell
function Test-BudgetAlert {
    param([double]$Actual,[double]$Budget,[string]$Owner="未指定")
    $ratio=$Actual/$Budget
    $level=if($ratio-lt 0.8){"绿区"}elseif($ratio-le 1.0){"黄区"}else{"红区"}
    [PSCustomObject]@{
        Level=$level; Ratio="$($ratio.ToString('P'))"
        Action=switch($level){"绿区"{"正常"}"黄区"{"周报提醒 $Owner"}"红区"{"超预算！限流/暂停非关键实例"}}
    }
}
Test-BudgetAlert -Actual 920 -Budget 1000 -Owner "后端团队"
```

### 7.4 闲置实例扫描（标签 + CPU 基线）

### 7.5 成本异常检测（3σ 移动平均）

```powershell
function Find-CostAnomaly {
    param([double[]]$DailyCost,[double]$Sigma=3)
    $mean=($DailyCost|Measure-Object -Average).Average
    $sd=[math]::Sqrt(($DailyCost|ForEach-Object{[math]::Pow($_-$mean,2)}|Measure-Object -Average).Average)
    $last=$DailyCost[-1]; $th=$mean+$Sigma*$sd
    [PSCustomObject]@{Mean=[math]::Round($mean,2);StdDev=[math]::Round($sd,2)
        Threshold=[math]::Round($th,2);Latest=$last;IsAnomaly=$last-gt$th
        Suggestion=if($last-gt$th){"触发异常，查突增来源"}else{"正常"}}
}
Find-CostAnomaly -DailyCost @(120,118,125,121,119,130,480)
```

## 八、案例研究

**案例 A 跨境电商 —— 全按需转混合架构**
背景：2C4G×8 全按需，月 ¥3,200，大促卡顿。动作：稳定基载 5 台转包年（省 45%），3 台峰值留按需；静态接 CDN（出流量 −72%）；数据库盘降高性能云盘（省 30%）。结果：月 ¥3,200 → ¥1,780（**−44%**），大促更稳，回收期 < 2 月。

**案例 B AI 训练 —— 竞价 + 检查点**
背景：全按需 GPU，月 ¥18,000，任务常因成本被砍。动作：训练无状态化 + 每 10 分钟检查点；多规格回退（3 种 GPU）；非高峰跑。结果：单位训练成本 −68%，月 ¥18,000 → ¥5,800，零进度损失。

**案例 C SaaS 初创 —— 单用户成本失控**
背景：客单价 ¥29/月，单用户 TCO ¥14（48%），毛利被压。动作：Right-sizing 降配 1 档（−38% 计算）；日志转冷（−60% 存储）；关停 6 台遗忘预发机。结果：单用户成本 ¥14 → ¥6.2（**21%**），毛利转正。

## 十、FAQ

**Q1 预留买几年最划算？** 利用率 >80% 且稳定 → 3 年；60%~80% → 1 年；波动大 → 不买，用按需+竞价。

**Q2 竞价被回收会丢数据吗？** 做到无状态化 + 检查点就不会，状态严格外置到对象存储/数据库。

**Q3 Right-sizing 影响性能吗？** 看 P95 峰值而非均值；峰值 <50% 降一档基本无感知，降后跑 1 周监控确认。

**Q4 小团队要做 FinOps 吗？** 要，但轻量：先 Showback（看钱花哪），再上预算告警，最后 Chargeback。

**Q5 CDN 一定省钱吗？** 动态内容多主要提速度而非省钱；静态资源多通常省 60%+ 出流量。

**Q6 多云会更贵吗？** 过度分散增运维成本；建议"主力云 + 弹性云"双云，而非 N 云各放一点。

**Q7 怎么说服老板？** 用 ROI：回收期 < 3 月的项目投入产出比一目了然，附本手册 TCO 算法即可。

**Q8 最易被忽略的隐藏成本？** 出网带宽 + 快照蔓延，两者常占 TCO 20%~35%。
